# perpose.md

Obsidian is take to much time to load. And don't have widget on phone. So i want to create a simple app that work similar to obsidian, i mean local markdown format notes but first-er load time and widget support.
In obsidian we select folder as vault in the same way in my app user can select folder as vault. create markdown notes basic edit, live preview etc. Most important part is the home screen widget, i want to make it a powerful tool and the core selling point. user can easily capture quick notes. In the home screen widget user can create note, edit note, view notes, select folder etc. My intention is not replacing obsidian, my intention is make it obsidian helper.

i tried many time but failed to load markdown files in the app like obsidian vault. And also struggling with building the widget, where user can select vault folder, create notes on specific folders with out opening the app.
